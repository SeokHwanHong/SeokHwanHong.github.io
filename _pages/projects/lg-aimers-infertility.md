난임 시술 데이터를 바탕으로 **임신 성공 여부를 예측**한 LG Aimers 6기 AI 해커톤 프로젝트다. 의료 데이터를 다루되, 실제 임상 의사결정을 대신하는 모델이 아니라 대회 데이터에서 예측 성능을 높이는 것이 목표였다. 팀은 예선 **상위 3%**로 오프라인 본선에 진출했다.

## 프로젝트 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 문제 | 난임 시술 기록으로 임신 성공 여부 예측 |
| 데이터 | 전처리 기준 126,244건, 수치·범주·범위형·조건부 결측치가 혼재 |
| 주요 모델 | CatBoost, LightGBM, AutoGluon, 앙상블 |

| 담당 | 파생변수 설계, 전처리·결측값 처리, 모델 탐색과 검증 결과 분석 |

## 1. 문제를 모델보다 먼저 해석하기

이 데이터의 어려움은 단순히 열이 많다는 데 있지 않았다. `이전 총 임신 횟수`, `총 생성 배아 수`, `난자 출처`처럼 서로 다른 의미를 가진 값이 한 테이블에 들어 있었고, 일부 횟수 열은 숫자가 아니라 `"6회 이상"` 같은 범위형 문자열이었다. 또 배아 관련 다섯 변수는 같은 행에서 함께 비어 있는 경우가 많았다.

처음에는 일반적인 결측값 대치로 처리할 수 있다고 생각하기 쉽다. 하지만 시술 유형이 `DI`인 경우처럼 **시술 과정상 특정 난자·배아 정보가 존재하지 않는 상황**이 있었다. 이 경우 결측은 평균으로 채워야 할 누락이 아니라, 치료 과정의 상태를 나타내는 정보일 수 있다. 따라서 값만 채우는 방식보다 다음을 분리해 해석하는 것을 우선했다.

- 범위형 횟수는 수치형과 범주형 표현을 각각 만들 수 있도록 정리
- 시술 유형과 난자·정자 출처의 조합에서 결측이 자연스러운 경우를 확인
- 희소한 상위 횟수 범주(`6회 이상`)는 단순 수치로 보지 않고 별도 처리 가능성을 검토
- 불임 원인이 여러 개 동시에 나타나는지를 합계 변수로 표현

이 과정에서 `불임 원인 세부 합계`, `이전 IVF 시술 횟수 + 이전 DI 시술 횟수`로 만든 총 시술 횟수, 신규 시술 여부처럼 **환자의 이전 시술 맥락**을 담는 변수를 추가했다.

## 2. 파생변수는 치료 과정을 더 잘 설명해야 했다

모델의 입력을 늘리는 것보다, 서로 떨어져 있던 정보를 치료 과정의 관점에서 연결하는 데 집중했다.

| 파생변수 | 설계 의도 |
| --- | --- |
| 불임 원인 세부 합계 | 난관 질환·배란 장애·남성 요인·자궁내막증·불명확 원인이 동시에 나타나는 정도 반영 |
| 총 시술 횟수 | 이전 IVF와 DI 경험을 하나의 시술 이력으로 통합 |
| 신규 시술 여부 | 이전 IVF·DI 시술 횟수가 모두 0인 사례를 구분 |
| 복합 배아 사용 여부 | 신선·동결·기증 배아의 복합 사용 여부를 분리 |
| 이전 성공 횟수 / 총 시술 횟수 | 이전 치료 이력을 단순 횟수보다 비율로 표현 |
| 난자·정자 출처 × 기증자 나이 | 출처와 연령대가 함께 가지는 정보를 범주형 상호작용으로 반영 |

수치형으로 변환한 배아 수·난자 수·시술 횟수와 원래 범주형 표현을 함께 유지한 이유도 여기에 있다. 예를 들어 횟수의 크기는 수치 정보가 되지만, `6회 이상`은 선형적인 한 단계 증가와 다른 의미를 가질 수 있다. CatBoost처럼 범주형 변수를 직접 다룰 수 있는 모델을 주력으로 둔 배경이다.

## 3. 한 모델의 점수보다, 보지 못한 데이터에서의 일관성을 확인

CatBoost, LightGBM, AutoGluon을 각각 비교하고, 서로 다른 모델의 예측을 앙상블했다. 모델 선택은 한 번의 검증 점수만으로 결정하지 않았다. 5-Fold CV와 별도 검증 결과를 보며, 특정 분할에서만 좋아지는 모델보다 **새로운 환자 기록에서도 흔들림이 적은 조합**을 찾는 데 초점을 맞췄다.

CatBoost 학습 로그에서는 AUC가 0.6766에서 시작해 408번째 기록 시점에 **0.72365**, Logloss **0.51249**까지 개선됐다. 이 수치는 최종 대회 순위 점수가 아니라, 범주형·결측치 처리 전략을 검증하기 위해 남긴 모델 실행 기록이다.

| CatBoost 검증 기록 | AUC | Logloss |
| --- | ---: | ---: |
| 초기 기록 | 0.67656 | 0.69108 |
| 최고 기록 시점(학습 407회) | **0.72365** | **0.51249** |

최종 제출에서는 각 모델이 잘 맞추는 사례가 다를 수 있다는 점을 활용했다. CatBoost는 복잡한 범주형 조합과 결측 패턴을 다루는 데, LightGBM과 AutoGluon 기반 모델은 다른 분할 방식과 탐색 공간에서 보완적인 예측을 제공했다. 이 결과를 앙상블해 Private 데이터에서도 성능을 유지하는 방향으로 제출 파일을 구성했다.

## 4. 결과를 해석하며 남긴 기준

예선 상위 3%와 본선 진출은 의미 있는 결과였지만, 이 프로젝트에서 더 중요했던 것은 **결측값과 범주를 데이터 오류로 단정하지 않는 습관**이었다. 의료·시술 데이터는 값이 없는 이유 자체가 과정의 일부일 수 있다. 이후 비슷한 문제에서는 다음을 더 보완하고 싶다.

- 시간·기관·환자군이 바뀌었을 때도 유지되는지 외부 검증
- 연령대·시술 유형별 오류와 확률 보정(calibration) 점검
- 실제 의사결정에 사용할 경우 임상 전문가 검토와 편향·설명 가능성 평가

> 이 글의 수치와 변수 설계는 대회 발표 자료·실험 메모·학습 로그를 기준으로 정리했다. 예측 결과는 대회 분석 경험을 기록한 것이며, 의료적 판단이나 상담을 위한 도구가 아니다.
