2025 인하 인공지능 챌린지 대학원 부문에서 수행한 멀티모달 이미지 생성 프로젝트다. 흑백 이미지와 자연어 캡션을 입력받아 색을 입힌 뒤, 초해상도로 세부 질감을 복원했다. 팀은 **대학원 부문 우수상**을 수상했다.

## 프로젝트 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 문제 | 자연어 설명을 반영한 흑백 이미지 색채화와 초해상도 복원 |
| 학습·평가 데이터 | 학습용 65,260장, 평가용 200장 |
| 평가식 | `0.6 × HSV Similarity + 0.4 × CLIP Score` |
| 최종 파이프라인 | L-CAD 색채화 → SwinIR 2× 초해상도 → 제출 파일 생성 |
| 비교 모델 | Real-ESRGAN, SwinIR, ResShift |
| 성과 | SwinIR: 공개 평가 0.6830 / 비공개 평가 **0.6925**, 대학원 부문 우수상 |

## 1. 색을 채우는 문제이자, 문장을 이해하는 문제

입력은 512×512 흑백 이미지와 캡션이다. 단순히 자연스러운 색을 채우는 것만으로는 충분하지 않았다. 평가지표에는 실제 이미지와의 HSV 히스토그램 유사도뿐 아니라, 생성 이미지가 캡션과 얼마나 잘 맞는지를 보는 CLIP 점수도 포함됐다.

예를 들어 캡션에 `yellow sign`, `red writing`, `red white and blue flag`처럼 색 단서가 주어졌을 때, 이미지의 어느 객체에 이를 반영할지 판단해야 한다. 그래서 이미지의 윤곽을 보존하면서 텍스트 조건을 반영하는 색채화 모델과, 손실된 고주파 세부 정보를 복원하는 초해상도 모델을 하나의 파이프라인으로 구성했다.

## 2. 512×512에서 바로 색칠하지 않은 이유

기본 접근은 Canny edge와 Stable Diffusion을 이용해 원본 해상도에서 바로 색채화를 수행하는 방식이었다. 그러나 512×512 출력을 직접 만들면 일부 영역에 색이 채워지지 않은 픽셀이 남는 문제가 관찰됐다. 색채화의 일관성을 먼저 확보한 뒤 해상도를 복원하는 편이 낫다고 판단했다.

![L-CAD 색채화 뒤 SwinIR로 2배 복원한 이미지 예시](/images/projects/inha-ai-challenge/swinir-output.png)

*색채화 결과를 SwinIR로 2배 복원한 출력 예시*

이에 따라 처리 순서를 다음처럼 나눴다.

1. **해상도 축소**: 512×512 입력을 256×256으로 축소해 색채화 모델이 일관된 색 분포를 만들도록 했다.
2. **텍스트 조건 색채화**: L-CAD에 저해상도 흑백 이미지와 캡션을 입력해 색채 이미지를 생성했다.
3. **2배 초해상도**: 색채화된 256×256 이미지를 SwinIR로 512×512까지 복원했다.
4. **제출 형식 변환**: 파일명과 테스트 ID를 맞춰 제출 형식을 생성했다.

L-CAD는 휘도(luminance) 정보와 텍스트 조건을 잠재 공간(latent space)에 함께 반영하는 diffusion 기반 색채화 모델이다. 이 프로젝트에서는 모델을 새로 학습하지 않고 추론 중심으로 사용했다. 따라서 "색을 잘 입히는가"와 "업스케일링이 색채화 결과를 훼손하지 않는가"를 분리해 확인하는 것이 특히 중요했다.

## 3. 초해상도 모델은 결과의 마지막 품질을 좌우했다

색채화 뒤에는 서로 다른 복원 방식의 세 모델을 비교했다.

| 모델 | 접근 | 공개 평가 | 비공개 평가 |
| --- | --- | ---: | ---: |
| Real-ESRGAN | GAN 기반 실사 복원 | 0.6700 | - |
| **SwinIR** | Swin Transformer 기반 이미지 복원 | **0.6830** | **0.6925** |
| ResShift | 잔차 이동 기반 diffusion 초해상도 | 0.6652 | - |

SwinIR을 선택한 이유는 점수뿐 아니라, Transformer의 window attention이 이미지 전역 문맥과 국소 질감을 함께 복원하는 방식이 이 파이프라인에 잘 맞았기 때문이다. L-CAD가 만든 색의 방향을 크게 흔들지 않으면서 가장자리와 세부 질감을 보완했다.

내가 맡은 역할은 두 단계 파이프라인의 결합, 초해상도 후보 모델 탐색·실험, 단계별 출력 비교였다. 여기서 중요한 판단은 "가장 강한 단일 모델"을 찾는 것보다 앞 단계 출력의 오류를 다음 단계가 어떻게 증폭하거나 완화하는지 확인하는 일이었다.

## 4. 한계와 다음 실험

이번 결과에는 분명한 한계도 있었다. L-CAD와 초해상도 모델을 모두 별도 재학습 없이 추론으로 사용했고, 색채화는 512→256, 초해상도는 256→512으로 수행해 전후 단계의 해상도 조건이 완전히 같지 않았다. 추가 전처리·후처리, guidance scale, 추론 단계 수, 초해상도 설정을 체계적으로 탐색할 여지가 남았다.

다음 실험에서는 색채화 품질과 초해상도 품질을 분리한 검증 세트를 만들고, 캡션 유형별(CLIP 단서가 강한 경우·약한 경우) 오류를 분석하고 싶다. 그래야 전체 점수뿐 아니라 어느 단계에서 오류가 발생하는지 더 명확하게 파악하고 개선할 수 있다.
