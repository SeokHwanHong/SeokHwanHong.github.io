재생에너지 비중이 높은 노르웨이의 전력망 데이터를 바탕으로, 세 전력망의 시간별 손실량을 예측한 프로젝트다. 통계적 시계열 모델과 트리 기반 모델을 모두 적용해 보며, 계절성을 설명하는 일과 실제 예측 오차를 낮추는 일이 반드시 같은 결과로 이어지지는 않는다는 점을 확인했다.

## 1. 왜 전력망 손실을 예측하는가

발표 자료에서는 전력망 손실을 사전에 예측하고 대응하는 일이 운영 비용과 안정성에 연결된다고 보았다. 노르웨이는 재생에너지 비중이 높은 사례이므로, 수요·온도·부하량이 함께 변동하는 환경에서 손실을 예측하는 과정을 국내 전력망에도 적용할 수 있는 분석 관점으로 삼았다.

데이터는 Kaggle의 Grid Loss Prediction 데이터셋으로, 세 전력망에서 시간 단위로 측정한 수요량(demand), 부하량(load), 온도, 손실(loss)을 담고 있다. EDA에서는 전력망별 추세를 분리해 보고, 온도–수요량, 온도–부하량, 수요량–부하량의 관계를 산점도로 확인했다. 같은 변수라도 전력망별 분포와 변동 폭이 달랐기 때문에 하나의 단순 회귀식으로 묶기보다 **전력망별 모델 결과**를 따로 비교했다.

## 2. 먼저 SARIMAX로 계절성과 외생 변수를 설명

시계열 패턴을 분석한 결과 24시간 주기가 관찰되어 계절 차분을 적용했다. 수요량과 부하량에는 24시간 계절 차분 뒤 1차 일반 차분을, 온도에는 물리적 성격이 다르다는 판단으로 24시간 계절 차분만 적용했다. ACF·PACF를 확인한 뒤 수요량·load·온도를 외생 변수로 넣어 SARIMAX를 학습했다.

| 전력망 | SARIMAX `order` | `seasonal_order` |
| --- | --- | --- |
| Grid 1 | (1, 1, 1) | (0, 1, 1, 24) |
| Grid 2 | (0, 1, 1) | (0, 1, 1, 24) |
| Grid 3 | (0, 1, 1) | (0, 1, 1, 24) |

이 접근은 어떤 계절성과 외생 변수가 손실에 관계하는지 해석하는 데 유용했다. 그러나 테스트 구간의 실제 변동을 따라가는 예측 성능은 충분하지 않았다. 특히 Grid 1의 SARIMAX 예측은 실제 손실과 다른 장기 추세를 보였고, RMSE가 크게 나타났다.

## 3. 물리적·시간적 특징을 넣어 XGBoost로 전환

SARIMAX의 한계를 보완하기 위해, 전력 손실이 전류 제곱에 비례한다는 도메인 가설을 참고해 부하량 제곱 특성인 `load_square`를 만들었다. 여기에 수요량 대비 부하량 비율, load와 온도의 곱, 시간·요일·월을 추가했다.

| 파생변수 | 의도 |
| --- | --- |
| `load_square` | 부하량의 비선형적 영향 반영 |
| `load / demand` | 수요 대비 부하량의 상대적 상태 표현 |
| `load × temperature` | 기온과 부하량의 상호작용 반영 |
| `hour` / `dayofweek` / `month` | 시간대·주간·월간 패턴 반영 |

시간 순서를 유지해 앞 80%를 학습에, 뒤 20%를 검증에 사용했다. XGBoost는 1,000개 트리, learning rate 0.05, max depth 5, random seed 42로 학습했고, gain 기준의 특성 중요도도 함께 점검했다.

## 4. 모델 비교: XGBoost가 낮춘 예측 오차

같은 테스트 구간에서 RMSE를 비교한 결과, 세 전력망 모두 XGBoost가 더 낮은 오차를 보였다.

| 전력망 | SARIMAX RMSE | XGBoost RMSE | 오차 감소 |
| --- | ---: | ---: | ---: |
| Grid 1 | 35.330 | **3.125** | 91.2% |
| Grid 2 | 11.497 | **4.011** | 65.1% |
| Grid 3 | 2.396 | **0.371** | 84.5% |

![Grid 1, Grid 2, Grid 3의 XGBoost 실제값과 예측값 비교](/images/projects/norway-power-grid/xgboost-predictions.png)

*각 전력망의 실제 손실(파랑)과 XGBoost 예측(주황) 비교*

Grid 1과 Grid 2는 변동성이 큰 구간에서도 전반적인 수준과 하락·상승 구간을 따라갔고, Grid 3은 상대적으로 낮은 손실이 이어지는 구간을 잘 근사했다. 반면 급격한 이상 변동은 여전히 어려웠다. 즉 XGBoost가 모든 사건을 맞혔다기보다, 시간·수요·부하량·온도 사이의 비선형 관계를 학습해 평균 예측 오차를 크게 줄인 결과로 해석했다.

## 5. 실행 기록에서 발견한 개선 지점

실험 로그를 다시 확인하면서 한 가지 구현상 주의점도 찾았다. `XGBRegressor`에 넣은 `validation_fraction`과 `n_iter_no_change`는 사용한 XGBoost 학습에서 적용되지 않는다는 경고가 남아 있었다. 따라서 이 결과를 "조기 종료(early stopping)까지 적용한 최적 모델"이라고 해석하면 안 된다.

다음에는 시간 순서 기반 `eval_set`과 명시적인 조기 종료를 사용하고, 롤링 검증(rolling validation)으로 여러 시점의 일반화 성능을 비교할 예정이다. 또한 미래 시점에서 실제로 미리 알 수 있는 외생 변수만 쓰도록 데이터 누수도 점검해야 한다. 이 두 가지를 보완하면 통계 모델의 해석력과 머신러닝 모델의 예측력을 더 공정하게 비교할 수 있다.

> 본문 수치와 그래프는 팀 발표 자료와 실행 노트북의 저장된 결과를 기준으로 정리했다.
