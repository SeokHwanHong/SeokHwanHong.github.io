LG Aimers 8기 모델 경량화 온라인 해커톤에서 **EXAONE 4.0-1.2B**를 대상으로, 제한된 자원에서도 성능과 추론 효율의 균형을 찾는 경량화 파이프라인을 설계했다. LG Aimers 6기의 난임 예측 프로젝트와는 별개의 프로젝트다.

## 프로젝트 한눈에 보기

| 항목 | 내용 |
| --- | --- |
| 과제 | EXAONE 4.0-1.2B의 모델 크기·추론 속도·성능 균형 최적화 |
| 데이터 | RAG로 생성한 질의응답 1,000건, 학습·검증 9:1 분할 |
| 학습 방식 | 4-bit QLoRA 기반 supervised fine-tuning |
| 핵심 설정 | Attention·MLP 레이어 선택 학습, BF16 병합 |
| 결과 | Score 0.5200 → 0.5938, 압축 파일 약 1.9GB |
| 담당 | RAG 데이터셋 설계, QLoRA 학습 파이프라인과 하이퍼파라미터 설정, 결과 분석 |

## 1. 목표: 성능만이 아닌 배포 가능한 균형

평가는 기본 모델 대비 성능 비율과 토큰당 추론 시간 감소 비율을 각각 50%씩 반영했다. 단순히 모델을 줄이거나 성능 보존만을 목표로 해서는 충분하지 않았기에, **기존 성능을 가능한 한 보존하면서 모델 크기와 추론 비용을 낮추는 것**을 목표로 잡았다.

## 2. 데이터: 벤치마크 범위를 RAG 학습 데이터로 전환

가중치가 높은 한국어 LLM 벤치마크를 참고해 지식·추론·응용 영역을 나눴다. KMMLU·KMMLU-HARD, HRM8K·AIME, MT-Bench·ARC-AGI, HumanEval·SWE-bench를 기준으로 질의응답 데이터 1,000건을 구성하고 9:1로 학습·검증 데이터를 분할했다.

단순한 정답 복원이 아니라 지식 질의와 수학·논리 추론, 코딩 과제를 함께 다룰 수 있는 학습 분포를 만드는 것이 목적이었다. 답변에는 사고 과정을 따르는 구조를 반영해 단답형 생성에 치우치지 않도록 했다.

## 3. 접근: 4-bit QLoRA와 선택적 레이어 학습

전체 가중치를 다시 학습하는 대신, 4-bit로 양자화한 기반 모델에 LoRA 어댑터를 붙여 supervised fine-tuning을 수행했다. 문맥 흐름과 지식·추론 처리에 직접 관여하는 Attention과 MLP 계열 레이어를 학습 대상으로 삼았다.

| 구분 | 설정 |
| --- | --- |
| Target modules | q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj |
| LoRA rank / alpha | 16 / 32 |
| LoRA dropout | 0.10 |
| Epoch | 1 |
| Learning rate | 2e-5 |
| Scheduler / warmup | cosine / 0.05 |

파이프라인은 RAG 데이터 생성 → 토크나이징·9:1 분할 → 4-bit QLoRA 학습 → BF16 가중치 병합 → 압축 모델 내보내기 순서로 구성했다. LangGraph로 과정을 모듈화해 데이터 준비와 학습·저장 단계를 분리했다.

## 4. 결과: 점수 개선과 모델 크기 감소를 함께 확인

| 방법 | Score |
| --- | ---: |
| Baseline | 0.5200 |
| Proposed | **0.5938** |
| 1위 점수 | 0.6470 |

제안 방법은 baseline보다 **0.0738** 높았다. 최종 압축 파일은 약 **1.9GB**로, 기본 모델 크기 4.79GB 및 기본 압축 크기 3.97GB보다 작았다. 제한된 자원에서 학습 구조를 조정해 배포 가능성을 높였다는 점에 의미가 있다.

## 5. 한계와 다음 개선

고품질 데이터의 양이 충분하지 않았고, LangGraph 워크플로우가 선형 구조에 머물렀다. 또한 LoRA 설정과 데이터 구성에 대한 폭넓은 탐색이 부족했다. 다음에는 벤치마크별 실패 사례를 분석해 데이터 비중을 조정하고, 추론·코딩 영역별 하이퍼파라미터 탐색과 비선형 검증 루프를 추가해 점수와 일반화 성능을 함께 개선하고자 한다.
