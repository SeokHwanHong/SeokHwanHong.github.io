## 1. 자동차 제조의 큰 흐름

차체를 중심으로 한 제조 공정은 다음 순서로 진행된다.

|       공정       | 투입물                  | 주요 작업                           | 결과물                    |
| :--------------: | ----------------------- | ----------------------------------- | ------------------------- |
| **프레스** | 금속 판재               | 자르고 눌러서 부품 형상 제작        | 도어, 후드 등 차체 패널   |
|  **차체**  | 개별 차체 부품          | 부품을 위치에 맞춰 접합             | 자동차의 골격인 차체      |
|  **도장**  | 접합된 차체             | 표면 처리와 도료 도포 및 건조       | 보호층과 색상을 갖춘 차체 |
|  **의장**  | 도장된 차체와 각종 부품 | 실내외 부품, 구동계 및 배선 등 조립 | 완성된 차량               |

엔진, 모터, 배터리, 시트 등은 별도의 생산 과정에서 만들어져 조립 공정으로 공급되므로, 자동차 제조 저체가 하나의 직선으로만 구성되지는 않는다.

## 2. 공정의 이해

### 2.1. 프레스 공정

#### 2.1.1. 정의

프레스 공정이란 평평한 금속 판재를 입체적인 부품으로 만드는 과정이다. 자동차의 문, 후드, 지붕, 바닥 등이 이 과정을 통해 생성된다. 이 공정에서 프레스 설비란 금속을 가공할 힘과 움직임을 제공하는 기계, 금형은 금속을 원하는 모양으로 만들기 위한 도구를 의미한다. 동일한 프레스 설비라도 금형을 바꾸면 다른 형상의 부품을 생산 가능하다.

#### 2.1.2. 작업 순서

 작업은 보통 소재 준비, 성형, 절단 및 구멍 가공, 가장자리 가공 등으로 구분된다.

|             단계             | 작업                                           | 필요 이유                    |
| :---------------------------: | ---------------------------------------------- | ---------------------------- |
|  **소재 준비&블랭킹**  | 판재를 펼쳐 가공에 필요한 크기와 윤곽으로 자름 | 금형에 넣을 소재 준비        |
|     **성형&드로잉**     | 판재를 금형으로 눌러 입체 형상 제작            | 곡면과 깊이가 있는 부품 제작 |
|    **트리밍&피어싱**    | 불필요한 가장자리 제거 및 구멍 천착            | 최종 윤곽과 조립 위치 확보   |
| **플랜징&리스트라이크** | 가장자리에 굴곡 생성 및 형상 재교정            | 접합할 부분과 최종 치수 확보 |

#### 2.1.3. 품질 문제 발생 원인

금속이 금형 모양을 따라 변형될 때, 부분마다 늘어나거나 압축되는 정도가 달라져서 품질 문제가 발생한다.

|           문제           | 설명                                              |
| :-----------------------: | ------------------------------------------------- |
|      **균열**      | 소재가 변형을 견디지 못해 갈라짐                  |
|      **주름**      | 소재가 불균일하게 압축되면서 접힘                 |
|    **스프링백**    | 힘을 제거한 뒤 탄성 회복으로 형상이 일부 되돌아옴 |
| **치수, 표면 문제** | 목표 형상에서 벗어나거나 표면이 손상              |

힘을 크게 가한다고 무조건 좋은 제품이 나오는 것이 아니다. 따라서 소재 특성, 금형 형상, 윤활과 작업 조건 등을 함께 고려해야 한다.

### 2.2. 차체

#### 2.2.1. 정의

차체 공정이란 개별 부품을 정확히 연결해 자동차의 골격을 만드는 과정이다. 프레서에서 나온 부품인 바닥, 측면, 지붕 등과 부분 조립체를 연결해 차체의 구조와 형상을 만든다. 도장 천 차체를 BIW(Body In White)라고도 한다.

#### 2.2.2. 작업

해당 공정의 핵심은 위치를 맞추는 작업과 접합하는 과정이다. 먼저 부품을 치구에 놓고 고정한다. 여기서 치구란 부품을 정해진 위치에 잡아주는 장치다. 위치가 어긋낫 상태에서 접합하면, 접합 자체가 튼튼해도 차체의 형상이 잘못될 수 있기 때문이다.

일반적으로 부분 조립체를 만든 뒤 전체 골격을 결합하고, 필요한 추가 접합과 도어나 후드 등의 장착 및 검사를 진행한다.

|         방법         | 원리                                                                     |
| :-------------------: | ------------------------------------------------------------------------ |
| **저항 점용접** | 겹친 금속판을 전극으로 누르고 전류를 흘려, 접촉부에서 발생하는 열로 접합 |
|  **아크용접**  | 전극과 소재 사이에 발생하는 전기 아크의 열을 이용해 접합                 |
| **레이저용접** | 레이저 에너지를 집중해 접합                                              |

#### 2.2.3. 품질 문제 발생 원인

차체는 주로 여러 부품이 오차가 누적되는 구조다. 개별 부품이 허용 범위 내라도, 조합된 결과에서 문제가 발생할 수 있다.

- 부품이나 치구의 위치 편차가 차체 치수에 영향
- 접합 조건이 맞지 않은 경우 접합부의 품질 저하
- 용접 열에 의해 변형 발생
- 도어와 주변 차체의 간격이나 높이가 상이

### 2.3. 도장

#### 2.3.1. 정의

도장 공정이란 색을 입히는 것뿐 아니라, 부식을 방지, 표변 보호, 외관 품질을 확보하는 과정이다. 금속 표면에 바로 색칠하면 오염으로 인해 도료가 잘 붙지 않거나, 필요한 보호 성능을 얻지 못하는 경우가 발생한다. 이를 방지하기 위해 표면 준비와 여러 층의 도막 형성이 필요하다.

#### 2.3.2. 작업순서

|        단계        | 작업                                                   | 목적                              |
| :-----------------: | ------------------------------------------------------ | --------------------------------- |
|  **전처리**  | 기름과 오염을 제거하고 표면을 처리                     | 도료가 잘 붙고 부식을 억제        |
| **전착 도장** | 차체를 도료가 포함된 액에 넣고 전기를 이용해 도막 형성 | 방청용 기본 보호층 형성           |
|   **실링**   | 접합부와  틈에 실러를 도포                            | 물 침투 방지 및 접합부 보호       |
|   **중도**   | 상도 아래의 도막을 형성                                | 표면과 최종 외관을 위한 바탕 형성 |
|   **상도**   | 색상을 구현하는 층과 클리어층 등을 형성                | 색상, 광택, 표면 보호             |
| **건조&경화** | 해당 도료와 공법에 맞는 조건으로 도막을 굳힘           | 필요한 도막 성능 확보             |
| **검사&수정** | 도막과 외관 상태를 확인하고 필요 시 수정               | 품질 확보                         |

#### 2.4.3. 품질 문제 발생 원인

일반적으로 도장은 표면 상태와 작업 환경의 영향을 함께 받기에 문제가 발생한다.

|             문제             | 설명                                      |
| :---------------------------: | ----------------------------------------- |
|        **이물**        | 도막에 먼지 등 이물질 등이 들어감         |
|      **흐름&처짐**      | 도료가 흘러 표면이 불균일해짐             |
|      **오렌지필**      | 표면에 귤껍질같은 요철이 발생             |
|   **색상&광택 편차**   | 목표 외관과 차이 발생                     |
| **도막 두께&경화 문제** | 도막이 필요한 두께나 성능을 확보하지 못함 |

### 2.4. 의장

#### 2.4.1. 정의

의장 공정이란 차체에 부품과 시스템을 조립해 차량을 완성하는 과정이다. 해당 공정에 들어오는 차체는 외형과 도장은 갖췄지만, 운행이 가능한 수준은 아니다. 내장재, 유리, 시트, 배선, 구동계 등 여러 부품을 조립함으로써 비로소 한 대의 차량이 완성된다. 전기차의 경우 구동계 구성이 모터와 배터리 등 차량 구조에 따라 상이한 부품으로 이루어진다.

#### 2.4.2. 작업 범주

|            단계            | 대표 작업                          |
| :------------------------: | ---------------------------------- |
|   **실내외 조립**   | 기름과 오염을 제거하고 표면을 처리 |
|  **전장&배관 연결**  | 배선과 커넥터, 배관 연결           |
| **하부&구동계 조립** | 구동계와 서스펜션 등 장착          |
|   **마무리&조정**   | 부품 장착 상태 확인과 필요한 조정  |

여러 부품을 미리 묶어 조립체로 준비하는 모듈 조립을 실시 후 차량에 장착하면, 차량 조립라인에서 해야할 작업을 감소시킬 수 있다.

#### 2.4.3. 품질 문제 발생 원인

차량마다 차종과 선택 사양이 다르므로 필요한 부품과 작업도 상이하다. 정확한 부품을 제떄 공급하고 해당 차량에 맞는 작업을 수행해야 한다.

| 문제 상황                                  |
| ------------------------------------------ |
| 다른 사양의 부품 장착 및 필요한 부품 누락  |
| 볼트 체결이나 커넥터 연결 미흡             |
| 부품 공급 지연으로 인한 작업 지연          |
| 특정 공정의 작업량이 많아 생산 흐름에 지장 |

따라서 의장에서는 제품 사양, 부품 공급, 작업 이력, 작업 시간, 검사 결과를 함께 보는 관점이 필요하다.

## 3. 공정에서 발생하는 문제 분석

### 3.1. 공정 구분

|       공정       | 핵심 확인사항                                  |
| :--------------: | ---------------------------------------------- |
| **프레스** | 소재를 목표 형상으로 만들었는가?               |
|  **차체**  | 부품을 정확한 위치에 충분한 품질로 연결했는가? |
|  **도장**  | 필요한 보호 성능과 외관을 확보했는가?          |
|  **의장**  | 차량 사항에 맞는 부품을  정확히 조립했는가?   |

문제가 발견된 공정과 문제가 시작된 공정은 다를 수 있다. 의장에서 부품이 잘 맞지 않는 문제가 발견됐더라도, 원인은 앞서 프레스 부품의 치수나 차체 조립 상태일 수도 있다.

#### 3.1.1. 공정 내 수집 항목 예시

|       공정       | 확인 사항              | 예시                                     |
| :--------------: | ---------------------- | ---------------------------------------- |
| **프레스** | 금속이 변형된 조건     | 성형 속도, 소재를 잡아주는 힘, 윤활 조건 |
|  **차체**  | 부품 접합 조건         | 용접 잔류, 용접 시간, 가압력             |
|  **도장**  | 도료 도포 및 경화 방법 | 도료 공급량, 분사 조건, 건조 온도&시간   |
|  **의장**  | 부품 조립 기준         | 체결 목표 토크, 체결 프로그램            |

#### 3.1.2. 데이터 참고시 구분 사항

|       구분       | 의미                           | 분석 질문                     |
| :--------------: | ------------------------------ | ----------------------------- |
| **설정값** | 작업에 적용하도록 지정한 값    | 적절한 조건을 선택했는가?     |
| **측정값** | 작업 중 실제로 관찰한 값       | 지정한 조건대로 작업하였는가? |
| **판정값** | 측정 결과에 기준을 적용한 결과 | 해당 기준을 만족했는가?       |

실제 데이터에서는 torque, temperature, pressure 등 다양한 이름의 변수로 구성되어 있으며, 단위, 측정 위치, 측정 시점, 평균 및 최대값 등 집계 방식을 확인할 필요가 있다. 예를 들어, 단순히 temperature 라는 변수의 의미가 공장 내 온도인지, 건조로 내부 공기 온도인지, 차체의 온도인지 등을 꼼꼼하게 확인해야한다.

### 3.2. 설비 상태

공정 조건을 확인 후 설비 상태를 확인해야 한다. 같은 작업 조건을 적용하더라도 설비나 도구의 상태가 상이할 수 있다. 공정 조건이 제품에 적용한 작업을 설명한다면, 설비 상태는 그 작업을 수행한 장비의 상태를 설명한다.

|                정보                | 확인 사항                            |
| :---------------------------------: | ------------------------------------ |
| **전류, 진동 등의 센서 기록** | 작업 중 설비의 동작이나 부하 변화    |
|         **알람 기록**         | 이상 및 작업 제한 감지 종류          |
|   **운전, 대기, 정지 상태**   | 센서 기록 당시 설비가 진행 중인 작업 |
|      **누적 작업 횟수**      | 설비나 도구의 사용 이력              |
|     **정비 및 교체 이력**     | 상태 변화 전후 조치 사항             |

이는 단지 원인 후보 확인 과정이며, 특정 설비에서 문제가 많다는 이유만으로 설비 고장이라고 결론을 내리는건 섣부르다. 해당 설비에서 다른 차종이나 작업을 담당했을 수도 있기에, 센서값 비교시 동일 작섭 수행 구간끼리 비교하는 것이 적절하다. 작업 중 전류와 대기 중인 전류를 섞어 평균을 낸다면 생산 구성의 변화가 설비 상태의 변화처럼 보일 수 있다.

### 3.3. 생산 이력

생산 이력을 통해 공정 조건과 설비 상태를 확보했더라도, 실제 문제 제품의 기록인지를 확인해야한다. 이는 분석 대상과 비교군을 정하는 기반이 된다. 다음은 예시 데이터와 연결 대상에 대한 표이다.

|               정보               | 연결 대상              |
| :------------------------------: | ---------------------- |
|  **부품, 차체, 차량 ID**  | 제품 종류              |
|    **소재, 부품 로트**    | 사용 소재 및 부품      |
|   **공정, 작업 위치 ID**   | 작업 종류              |
|     **설비, 공구 ID**     | 작업 내 사용 도구      |
| **작업 시작 및 종료 시각** | 작업 시간              |
|  **차종, 사양, 프로그램**  | 제품 및 작업 조건 종류 |
|       **작업 회차**       | 최초 작업, 재작업 분류 |

### 3.4. 품질 결과

앞선 내용들이 작업을 설명한다면, 품질 결과는 작업들의 결과를 설명한다. 품질 데이터에는 정상과 불량 판정뿐 아니라, 측정값, 검사 위치, 불량 유형과 검사 회차 등이 포함될 수 있다.

|             정보             | 필요 이유                            |
| :---------------------------: | ------------------------------------ |
|     **실제 측정값**     | 기준에서 벗어난 정도와 방향 확인     |
| **합격과 불합격 판정** | 규격 충족 여부 확인                  |
|  **검사 위치 및 항목**  | 어디에서 어떤 문제가 발생했는지 구분 |
|      **불량 유형**      | 상이한 문제들을 분리                 |
| **최초 및 재검사 구분** | 조치 전후 결과 구분                  |
|  **검사 기준 및 버전**  | 판정 기준 변경 여부 확인             |

예를 들어, 최초 검사에서는 불합격이지만 조정 이후 합격 판정을 받은 차량이 있다고

* 최초 작업 품질을 분석 -> 최초 불합격 정의 필요
* 출고 전 상태 확인 -> 최종 유효 판정 정의 필요
* 생산 손실 분석 -> 재작업 횟수와 시간 확인 필요

분석 전 어떤 항목들에서 불량을 구체적으로 정의하는 지 확인할 필요가 있다. 단순히 최종 합격만을 기준으로 한다면, 처음부터 합격한 차량과 재작업을 거친 차량이 동일 결과로 묶일 수도 있다.
