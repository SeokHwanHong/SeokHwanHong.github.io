# 1. Ruby 다운로드

ruby-lang.org/en/downloads/ 에서 Ruby+Devkit 설치 -> Ruby Installer 창에서 3번 설치 -> 종료

window + R -> cmd 실행 -> gem install jekyll, gem install bundler 입력

---

# 2. Power shell 실행

C:\SeokHwanHong-github-blog\SeokHwanHong.github.io 에서 shift + 우클릭 -> power shell 실행

power shell 에서 bundle install 입력

---

# 3. 서버 구동

power shell 에서 bundle exec jekyll serve 입력 -> 인터넷에 들어가 주소창에 localhost:4000 입력

# 4. 서버 종료

ctrl + "C" 2번 입력
