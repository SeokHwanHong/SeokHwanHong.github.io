# 1. 문법

특정 단어에 색상을 적용

```
<font color = "color">단어 or 문장</font>
```

# 2. Highlighting Texts

특정 문자의 배경에 형광펜처럼 색을 적용

```
<mark style = "background-color: #000000"> 단어 or 문장 </mark>

```
