## 260916: 네트워크 기초

이번 수업에서는 데이터를 표현하는 진법부터 IPv4 주소, 네트워크 계층과 전송 흐름까지 네트워크의 기초를 정리했다.

## 진법과 데이터 단위

- **bit**: 0 또는 1로 정보를 표현하는 최소 단위
- **byte**: 8bit로 구성된 단위

2진수는 컴퓨터가 데이터를 표현하는 기본 방식이다. 8진수와 16진수는 2진수를 사람이 더 짧게 읽고 쓰기 위해 사용하는 표현 방식이다. 특히 16진수 한 자리는 2진수 네 자리와 대응한다.

정수부는 진법 변환으로 정확하게 표현할 수 있지만, 소수부는 2진수로 유한하게 표현되지 않는 경우가 있다. 따라서 실수 연산에서는 표현 오차가 생길 수 있다.

## IPv4 주소와 클래스 기반 주소 체계

`127.0.0.1`은 현재 사용 중인 컴퓨터 자신을 가리키는 **루프백(loopback) 주소**다. 네트워크 프로그램을 외부와 연결하지 않고 시험할 때 사용할 수 있다.

과거 IPv4 주소는 첫 번째 옥텟을 기준으로 A~E 클래스로 나누어 사용했다. 현재는 주소를 더 유연하게 나누는 CIDR 방식이 일반적이지만, 주소 범위와 목적을 이해하기 위한 기초로 클래스 기반 체계를 알아둘 필요가 있다.

| 클래스 | 첫 번째 옥텟 범위 | 주요 용도 |
| --- | --- | --- |
| A | 1~126 | 대규모 네트워크 |
| B | 128~191 | 중간 규모 조직 |
| C | 192~223 | 소규모 네트워크 |
| D | 224~239 | 멀티캐스트 |
| E | 240~255 | 예약·실험용 |

`0`과 `127`로 시작하는 주소는 일반적인 A 클래스 호스트 주소로 사용하지 않는다는 점도 함께 구분한다.

## OSI 7계층과 TCP/IP 4계층

OSI 모델은 네트워크 통신을 일곱 개의 역할로 나눈 개념적 모델이고, TCP/IP 모델은 인터넷에서 실제로 널리 사용하는 네 개의 계층 모델이다.

OSI의 응용·표현·세션 계층은 TCP/IP의 응용 계층으로 묶인다. 전송 계층은 TCP와 UDP처럼 데이터 전달 방식을 담당하고, 네트워크 계층은 IP 주소를 바탕으로 목적지까지의 경로를 결정한다. 데이터링크와 물리 계층은 이더넷과 같은 실제 전송 매체·프레임 처리를 담당한다.

## 데이터 전송 흐름

데이터를 외부 네트워크로 보낼 때는 일반적으로 다음과 같은 경로를 거친다.

`PC → 게이트웨이 → 라우터 → 목적지 네트워크`

- **게이트웨이**: 다른 네트워크로 나가기 위한 출구 역할을 한다.
- **라우터**: IP 주소를 기준으로 목적지까지의 경로를 선택한다.
- **리피터**: 약해진 신호를 증폭해 더 멀리 전달할 수 있도록 돕는다.

각 계층과 장비의 역할을 구분해두면, 통신 오류가 생겼을 때도 어느 구간을 먼저 확인해야 하는지 체계적으로 판단할 수 있다.
